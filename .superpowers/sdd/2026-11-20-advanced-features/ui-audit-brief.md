## Области аудита и улучшения

### 1. Массовое создание профилей (`src/components/bulk-create-dialog.tsx`)
- Проверить отступы, сетку полей, модальное окно на разных разрешениях экрана.
- Проверить предпросмотр распознанных строк CSV/JSON: читаемость таблицы, скроллбар, выравнивание колонок, бейджи ошибок валидации.
- Добавить четкие подсказки (tooltips / placeholders) с примерами формата CSV и JSON.
- Убедиться, что кнопка подтверждения неактивна, если профилей 0 или есть фатальные ошибки валидации.

### 2. Запуск с задержкой (Staggered Launch) (`src/components/staggered-launch-button.tsx`)
- Проверить всплывающее меню настройки интервала: аккуратность ползунка/инпута секунд (1-60 сек).
- Сделать красивую анимацию/индикацию прогресса запуска очереди профилей (чтобы пользователь видел, какой профиль запускается следующим и сколько секунд осталось).

### 3. Авто-ротация мобильных прокси (`src/components/proxy-form-dialog.tsx`, `src/components/proxy-management-dialog.tsx`)
- Проверить секцию ротации: выравнивание переключателей (switch), поля для Change IP URL, селектора интервала (в минутах) и чекбокса «Ротировать перед запуском».
- Добавить информативный tooltip к ссылке смены IP (пояснение для новичков, что это GET/POST ссылка от провайдера).
- В списке прокси: проверить отображение бейджа мобильного прокси со статусом ротации.

### 4. Cookie Bot (`src/components/cookie-bot-enrol-dialog.tsx`, `src/components/cookie-management-dialog.tsx`)
- Пресеты: проверить карточки пресетов (`geo-ru`, `geo-us`, `geo-eu`, `tech-dev`, `crypto-web3`): визуальная сетка, отступы, иконки/флаги стран, бейджи количества сайтов.
- Экспорт/Импорт куки: проверить переключение табов, переключатель JSON / Netscape, удобство вставки большого текста, кнопку «Копировать в буфер» с анимацией успешного копирования.

### 5. Резервное копирование и Восстановление (`src/components/settings/backup-settings.tsx`)
- Проверить карточки в разделе «Резервное копирование» в `settings-dialog.tsx`.
- Кнопка «Показать/скрыть пароль» для поля шифрования.
- Выбор профилей (чекбокс «Выбрать все», бейдж с количеством выбранных).
- Индикатор процесса бэкапа/восстановления (spinner или progress bar) при упаковке больших папок.

### 6. Контекстное меню строки профиля (`src/components/profile-table/row-context-menu.tsx`)
- Пункт «Очистить кэш»: идеальное выравнивание иконки ластика (`LuEraser`), понятный toast после завершения («Освобождено X МБ дискового пространства»).

## Требования к реализации
1. Все изменения должны быть исключительно со знаком плюс: улучшать эргономику, визуал и отзывчивость без изменения базовой логики.
2. Использовать существующие компоненты дизайна shadcn/ui, radix, tailwind.
3. Поддерживать все 11 локалей при добавлении новых текстов.
4. Верификация:
   - `npx tsc --noEmit`
   - `cargo check -p donutbrowser` в `src-tauri`
